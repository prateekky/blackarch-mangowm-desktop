# Plugin patch attribution

These compatibility files modify community plugins for the Noctalia shell:

- `mango-displays/layout.luau` is derived from `prponkshe/mango-displays` (manifest declares MIT); it changes monitor rule spelling and matching for Mango 0.18.2.
- `nwg-displays/lib/nwg.luau` is derived from `micahg/nwg-displays` (MIT); its license text is included beside the patch. It routes profile selection through the Mango-aware helper.

Upstream sources are in the Noctalia community plugins repository: https://github.com/noctalia-dev/community-plugins
